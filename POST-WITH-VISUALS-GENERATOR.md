# SmartCart Post Generator WITH Visuals

This prompt generates **social posts + images + video scripts** you can use directly.

---

## Master Prompt (Copy & Paste Into Claude)

```
Generate a complete SmartCart social media post WITH visuals.

**POST DETAILS:**
- Platform: [TikTok / Instagram Reels / YouTube Shorts / Facebook]
- Day: [DATE - e.g., June 2, 2026]
- Topic: [e.g., "5-Minute Meals", "Meal Planner Feature", "Budget Meal Prep"]
- Hook: [e.g., "5-minute meals when you're STARVING"]

**APP CONTEXT:**
- App: SmartCart (meal planning app, grocery list, nutrition tracking, achievements)
- Audience: Busy young adults (20-35), health-conscious
- Voice: Playful, practical, relatable
- Do NOT mention premium features

**OUTPUT: Generate ALL of these sections:**

---

**SECTION 1: SOCIAL POST**
- Hook: [max 12 words]
- Caption: [Platform-appropriate length]
- Hashtags: 7 tags including #SmartCartMeals
- CTA: [Question or call-to-action]

---

**SECTION 2: IMAGE DESCRIPTION (for Midjourney/DALL-E)**
Detailed visual description that can be used to generate an image. Include:
- Main subject
- Color palette
- Composition/layout
- Style (cartoon, realistic, flat design, etc.)
- Mood/feeling
- Text overlays (if any)

Format: "Create a [style] image of [subject] with [color palette] colors, [composition]. [Mood]. Include text: '[text overlay]'"

---

**SECTION 3: VIDEO SCRIPT (for CapCut/Synthesia/TikTok)**
If video-based platform, generate:
- **Duration:** [15-30 sec for TikTok/Reels]
- **Scene 1 (0-5 sec):** [What happens, what text appears]
- **Scene 2 (5-10 sec):** [Second sequence]
- **Scene 3 (10-15 sec):** [Continuation]
- **Scene 4 (15+ sec):** [Conclusion/CTA]
- **Audio:** [Trending audio suggestion OR "upbeat background music"]
- **Text Overlays:** [Text that should appear on screen]
- **Transitions:** [How scenes change - cut/fade/zoom]

---

**TONE RULES:**
✅ Specific numbers ("save 3 hours", "$200")
✅ 1-3 emojis max
✅ Conversational, no jargon
✅ End with question or CTA
❌ No premium features
❌ No corporate speak

---

**OUTPUT FORMAT:**

# [DATE] — [TOPIC]

## 📱 SOCIAL POST

**Hook:** [text]

**Caption:** [text]

**Hashtags:** [tags]

**CTA:** [question/call-to-action]

---

## 🎨 IMAGE PROMPT (for Midjourney/DALL-E)

[Detailed visual description]

---

## 🎬 VIDEO SCRIPT (15-30 sec)

**Duration:** Xsec

**Scene 1 (0-Xsec):** [Description]
- **Text on Screen:** "[text]"
- **Action:** [what happens]

**Scene 2 (X-Xsec):** [Description]
- **Text on Screen:** "[text]"
- **Action:** [what happens]

[Continue for each scene]

**Audio:** [Music/sound suggestion]

**Final CTA:** [What should appear at end]

---
```
