# Phase 6: Retention Strategy — Keep Users Coming Back

## Overview

**Retention = Getting users to stay and use the app repeatedly.**

Most apps lose 70-80% of users within the first week. SmartCart's retention strategy focuses on:
1. **Email sequences** (post-install nurture)
2. **Push notifications** (timely reminders)
3. **In-app engagement hooks** (streaks, achievements)
4. **Win moments** (celebrate user progress)

### Code for Push Notifications

#### Request Permission (On First Launch)

```swift
// In ContentView or AppDelegate
import UserNotifications

func requestNotificationPermission() {
    UNUserNotificationCenter.current().requestAuthorization(options: [.alert, .sound, .badge]) { granted, error in
        if granted {
            DispatchQueue.main.async {
                UIApplication.shared.registerForRemoteNotifications()
            }
        }
    }
}
```

#### Send Local Notification

```swift
import UserNotifications

func sendWeeklyPlanningReminder() {
    let content = UNMutableNotificationContent()
    content.title = "Plan your week"
    content.body = "5 minutes to organize your meals"
    content.sound = .default
    content.badge = NSNumber(value: 1)
    
    // Sunday 8 AM
    var dateComponents = DateComponents()
    dateComponents.weekday = 1 // Sunday
    dateComponents.hour = 8
    dateComponents.minute = 0
    
    let trigger = UNCalendarNotificationTrigger(dateMatching: dateComponents, repeats: true)
    let request = UNNotificationRequest(identifier: "weekly_planning", content: content, trigger: trigger)
    
    UNUserNotificationCenter.current().add(request) { error in
        if let error = error {
            print("Error scheduling notification: \(error)")
        }
    }
}

// Send dinner reminder (6 PM daily)
func sendDinnerReminder() {
    let content = UNMutableNotificationContent()
    content.title = "What's for dinner?"
    content.body = "Open SmartCart to check your meal plan"
    content.sound = .default
    
    var dateComponents = DateComponents()
    dateComponents.hour = 18 // 6 PM
    dateComponents.minute = 0
    
    let trigger = UNCalendarNotificationTrigger(dateMatching: dateComponents, repeats: true)
    let request = UNNotificationRequest(identifier: "dinner_reminder", content: content, trigger: trigger)
    
    UNUserNotificationCenter.current().add(request) { error in
        if let error = error {
            print("Error scheduling notification: \(error)")
        }
    }
}

// Send on achievement unlock
func sendAchievementNotification(achievement: Achievement) {
    let content = UNMutableNotificationContent()
    content.title = "🏆 Achievement Unlocked!"
    content.body = achievement.name
    content.sound = .default
    
    let trigger = UNTimeIntervalNotificationTrigger(timeInterval: 1, repeats: false)
    let request = UNNotificationRequest(identifier: "achievement_\(achievement.id)", content: content, trigger: trigger)
    
    UNUserNotificationCenter.current().add(request)
}
```

## In-App Engagement Hooks

### 1. Cooking Streaks

**What:** Track consecutive days of cooking/meal planning

```swift
class StreakManager {
    @AppStorage("last_cook_date") var lastCookDate: Date = Date.distantPast
    @AppStorage("current_streak") var currentStreak: Int = 0
    @AppStorage("best_streak") var bestStreak: Int = 0
    
    func recordCooking() {
        let today = Calendar.current.startOfDay(for: Date())
        let lastDate = Calendar.current.startOfDay(for: lastCookDate)
        
        if Calendar.current.dateComponents([.day], from: lastDate, to: today).day == 1 {
            // Consecutive day
            currentStreak += 1
        } else if today > lastDate {
            // Break in streak
            bestStreak = max(bestStreak, currentStreak)
            currentStreak = 1
        }
        
        lastCookDate = Date()
        
        // Unlock achievement at 7, 30, 100 days
        if currentStreak == 7 || currentStreak == 30 || currentStreak == 100 {
            unlockAchievement("streak_\(currentStreak)")
        }
    }
}
```

### 2. Display Streak Prominently

```swift
// On Home screen
```

## Pro Tips

1. **Personalize emails** — Use actual user data (recipes they cooked, achievements unlocked)
2. **Time notifications** — Test different times, see what works for your users
3. **A/B test** — Try different email subject lines, push copy, notification times
4. **Listen to feedback** — Ask users what would make them come back
5. **Celebrate wins** — Users love seeing progress and achievements
6. **Don't spam** — More notifications ≠ better retention. Quality > quantity.
